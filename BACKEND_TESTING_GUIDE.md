## 11. Common Failure Patterns & Fixes

### "Cannot find module" errors
Your import paths may not match your actual file names. Check:
```bash
ls src/agents/
ls src/simulation/
ls src/contracts/
ls src/utils/
```
Then adjust the import statements in each test file to match the exact filenames.

### LLM returns non-JSON response
If an agent crashes parsing the LLM response, add a JSON extraction helper:
```typescript
function extractJSON(text: string): any {
  // Strip markdown fences
  let cleaned = text.replace(/```json\n?/g, "").replace(/```\n?/g, "").trim();
  // Find first { to last }
  const start = cleaned.indexOf("{");
  const end = cleaned.lastIndexOf("}");
  if (start === -1 || end === -1) throw new Error("No JSON found in LLM response");
  cleaned = cleaned.slice(start, end + 1);
  // Fix trailing commas
  cleaned = cleaned.replace(/,\s*([\}\]])/g, "$1");
  return JSON.parse(cleaned);
}
```

### Rate limit (429) from Gemini
The LLMClient should auto-fallback to Groq. If both are rate-limited, add a delay between test runs:
```bash
# Run tests with a 5-second gap
sleep 5 && APP_ENV=development npx ts-node src/tests/test-10-contradiction.ts
```

### Contract validation fails unexpectedly
Check that the YAML contract definitions match what your agents actually output. Common issues: field names don't match (camelCase vs snake_case), enum values differ, arrays returned as objects.

### Orchestrator hangs or times out
One of the 14 modules is likely stuck waiting for an LLM response. Add a timeout to llmClient.complete():
```typescript
const timeoutPromise = new Promise((_, reject) =>
  setTimeout(() => reject(new Error("LLM timeout after 30s")), 30000)
);
const result = await Promise.race([llmClient.complete(prompt), timeoutPromise]);
```

### Simulation state not propagating
If after_state variables don't carry over between actions, check that your simulator updates `this.currentState` after each successful action and passes it as `before_state` to the next.
